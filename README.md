# Voice Recording App

Кросс-платформенное приложение для записи системного аудио и голоса на базе Electron.

## Основные функции

- Запись системного аудио (браузеры, Zoom, Teams, Slack и др.)
- Запись с микрофона
- Транскрипция в реальном времени
- Генерация заметок встреч
- Интеграция с бэкендом
- Низкое потребление памяти (<150MB в режиме ожидания, <300MB при активном использовании)

## Требования

- Node.js 16+
- npm или yarn
- macOS или Windows

## Установка

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка приложения
npm run make
```

## Безопасность

- Шифрование данных при передаче (HTTPS)
- Безопасное хранение API ключей
- Шифрование локальных данных (AES-256)

## Архитектура

- Electron + React для UI
- Нативные модули для записи аудио
- WebSocket/REST API для взаимодействия с бэкендом
